# Bilan du jour — API de bilan vocal quotidien (2e passe)

## Fait
- `src/server/briefing/` : `types.ts` (contrat), `stories.ts` (regroupement d'articles en histoires), `collect.ts` (faits, garde-fous, fenêtres), `write.ts` (OpenAI Responses, validation, repli), `index.ts` (cache, verrou, limite).
- `src/app/api/briefing/route.ts` : `GET` (bilan du jour UTC, généré à la demande) et `POST` (régénération ; mêmes vérifs que `/api/agent` : hôte, Origin same-host, `X-Orbital-Client: aura`, JSON ; 429 + `Retry-After` si moins de 10 min).
- Réponse : `{ date, generatedAt, status: "ok"|"degraded", reason, chapters: [{ key, title, spokenText, sentences:[{text,factIds}], facts, windowHours, focus:{lat,lon}|null, writer:"ai"|"template"|"empty" }] }`. Chapitres : conflicts, politics, disasters, economy, space, nuclear, society, health. Chaque fait : sources (nom, URL, date, titre de l'article pour la presse), `headlines`, `independentSources`, `dateLabel` (« vendredi 16 octobre »), `unofficialSource`, `casualtiesAllowed`.

### 2e passe (demandes du chef d'orchestre)
1. **Presse = histoires.** Le regroupement générique pays+type est supprimé. Les articles (flux social GDELT 2.0 et événements de conflit GDELT 2.0) sont regroupés par similarité de titre : tokens normalisés (accents, pluriels, mots vides FR/EN, suffixe/préfixe de média ôté), même pays, et soit ≥ 2 mots communs avec Jaccard ≥ 0,3, soit ≥ 2 noms propres communs (les majuscules de début de phrase/proposition et les titres en Title Case ne comptent pas comme noms propres). Une histoire = un fait seulement avec ≥ 2 domaines distincts ; elle porte 2-3 titres, une source par domaine et `independentSources` ; tri par nombre de domaines. Articles sans titre réel (simple nom de domaine) ignorés. La rédaction n'a que les titres (consigne : rien d'ajouté).
2. **Fenêtres honnêtes.** 24 h d'abord ; chapitre vide -> politique, nucléaire, économie : 72 h ; santé : 7 jours. `windowHours` par chapitre. Toute phrase d'un chapitre élargi (et tout lancement planifié) est datée : le modèle est instruit, et le code préfixe la date (« Vendredi 16 octobre, … ») si la phrase l'omet. Un chapitre vide annonce sa vraie fenêtre (« … sur 72 h »).
3. **Économie.** Devises BCE et indices Yahoo Finance (non officiels) avec |Δ| ≥ 1,5 % ; l'indice est admis comme mesure de marché mais la phrase nomme toujours « Yahoo Finance, source non officielle » (imposé par le code, y compris dans le gabarit) et la séance est datée. L'économie est élargie à 72 h (ajout non demandé, nécessaire le week-end).
4. **Nucléaire.** Les publications ONU (un-news/un-press) dont le titre matche aiea/iaea/nucléaire/nuclear/uranium/enrichissement/plutonium/atomique/radioactif/Zaporijia/TNP sont routées vers le chapitre nucléaire (et retirées de la politique). WNN reste soumis à la règle des 2 domaines.

Garde-fous inchangés : source officielle (GDACS, USGS, EONET/NASA, OMS DON, ONU, BCE, UCDP/ACLED, LL2 pour les lancements) OU ≥ 2 domaines indépendants OU mesure de marché non officielle nommée ; jamais de bilan humain tiré de la presse (vocabulaire de victimes refusé dans toute phrase citant un fait non structuré, y compris dans le gabarit) ; témoignages (`published_report`), OVNI et thermique FIRMS exclus. Cache mémoire + `data/briefing/<date>.json` (ignoré par git) ; bilan `degraded` jamais écrit sur disque, gardé 15 min ; une seule génération concurrente ; régénération 1 / 10 min.

## Non vérifié / limites
- Routes HTTP non appelées (pas de serveur lancé). Le magasin local `data/intel-events.json` ne contient pas de titres GDELT 2.0 : en production, le chapitre conflits dépend de l'ingestion GDELT 2.0 du serveur (le collecteur lit `title`, ou le titre entre « » dans `source`). Sans titre, aucune histoire de presse (jamais de repli générique par pays). Dans l'essai, les événements GDELT 2.0 ont été relus via le connecteur.
- Regroupement par titre : heuristique lexicale. Titres dans des langues différentes sans nom propre commun ne fusionnent pas (histoire sous-comptée, jamais sur-comptée par pays seul) ; deux histoires proches (même ville, mêmes mots) peuvent encore fusionner, et une histoire peut être scindée en deux faits (observé : deux faits « No Kings »).
- Les phrases de presse reprennent les titres ; la traduction est faite par le modèle, le gabarit de repli laisse les titres dans leur langue.
- Économie : la variation Yahoo est celle de la dernière barre quotidienne (l'IDX Composite à -11,57 % du 16/10 est la donnée Yahoo brute, vérifiée par une requête ; non recoupée avec une autre source). Variations extrêmes à lire avec prudence.
- Nucléaire : WNN seul ne passe pas la règle des 2 domaines ; le chapitre repose surtout sur l'ONU. Le mot « centrale » seul n'est pas un déclencheur (ambigu) ; « centrale nucléaire » l'est via « nucléaire ».
- Le sujet ONU/politique peut être vide les week-ends (élargi à 72 h) ; santé souvent élargie à 7 jours (OMS publie peu).
- `ll2` est traité comme officiel pour les seuls événements planifiés. `focus` = premier fait géolocalisé du chapitre.
- Pas de planification automatique matinale ; bouton et lecteur vocal hors périmètre. `tests/aura-live-feeds.test.ts` (autre équipe) ignoré.
